gateway之路由配置

环境

  • idea 2025.1

  • jdk 17

  • spring-boot 4.0.4

  • spring-cloud 2025.1.1

  • spring-cloud-alibaba 2025.1.0.0

  • nacos 2.4

  • lombok 1.18.36

简介

Spring Cloud Gateway 的路由配置可分为：

  • 静态路由（YAML/Properties)
  • 动态路由 (API/数据库)

路由规则

路由配置核心分为三种：

  • 路由规则
  • 断言
  • 过滤器

这里使用webflux为例，其实两种网关方式，对于路由规则都是差不多。

配置路径有些许不同罢了。

  • webflux：spring.cloud.gateway.server.webflux.routes
  • webmvc：spring.cloud.gateway.server.webmvc.routes

¶核心字段

  1. id 路由标识符

    • **必须：**是
    • **类型：**String
    • 说明：路由的唯一标识，不能重复
    • 命名规则：
      • 使用小写字母、数字、下划线和连字符
      • 具有描述性，体现路由用途
      • 避免使用特殊字符

  2. url 目标服务地址

    • 必需：是

    • 类型：URI 字符串

    • 格式：协议://主机:端口[/路径]

    • 支持的协议格式：

      协议 示例 说明
      http/https https://api.example.com:8080 直接转发到具体服务实例
      lb (LoadBalancer) lb://user-service 通过服务发现转发
      ws/wss (WebSocket) ws://websocket-server:8080 WebSocket连接
      forward (内部转发) forward:/local/path 转发到网关内部一个Controller (如自定义鉴权返回特定试图，本地聚合数据)
      自定义 custom://my-protocol 需实现相关处理器

  3. order 执行顺序

    • 必需：否

    • 类型：Integer

    • 默认：0

    • 说明：数值越小优先级越高，多个路由匹配同一请求时使用

  4. predicates 断言

    • 必需：是（至少一个）

    • 类型：List

    • 说明：所有断言必须全部满足才会匹配该路由

    • 基本语法：

    • 完整断言工厂列表

      断言工厂 语法示例 说明
      After - After=2024-01-01T00:00:00.000+08:00 在指定时间后生效
      Before - Before=2024-12-31T23:59:59.000+08:00 在指定时间前生效
      Between - Between=2024-01-01T00:00:00.000+08:00, 2024-12-31T23:59:59.000+08:00 在时间段内生效
      Cookie - Cookie=sessionId, ^[a-zA-Z0-9]+$ Cookie 匹配正则
      Header - Header=X-Request-Id, \d+ 请求头匹配正则
      Host - Host=**.example.com, *.test.com 主机名匹配（支持通配符）
      Method - Method=GET,POST,PUT HTTP 方法匹配
      Path - Path=/api/**, /v2/** 路径匹配（支持 Ant 风格）
      Query - Query=name, zhangsan或 - Query=debug 查询参数匹配
      RemoteAddr - RemoteAddr=192.168.1.1/24, 10.0.0.1/16 IP 地址匹配
      XForwardedRemoteAddr - XForwardedRemoteAddr=192.168.1.1/24 允许基于 X-Forwarded-For（转发 ） HTTP 头部进行请求过滤
      Weight - Weight=group-a, 80 权重路由
      CloudFoundryRouteService - CloudFoundryRouteService=.* Cloud Foundry 特定

    • 注意：

      • Path 断言比配：几乎所有路由都应配置 Path 断言作为基础匹配条件
      • 避免过度匹配：断言条件越多，匹配成本越高，影响性能
      • 合理使用 Weight：灰度发布时确保同一组的权重总和合理分配
      • RemoteAddr 注意安全：在网关前只有负载均衡器（反代理）时，优先使用XForwardedRemoteAddr
      • 如需自定义断言，可实现org.springframework.cloud.gateway.handler.predicate.RoutePredicateFactory接口
