5.多重背包问题II

题目

有 N 种物品和一个容量是 V 的背包。

第 i 种物品最多有 si件，每件体积是 vi，价值是 wi。

求解将哪些物品装入背包，可使物品体积总和不超过背包容量，且价值总和最大。
输出最大价值。

输入格式
第一行两个整数，N，V，用空格隔开，分别表示物品种数和背包容积。

接下来有 N 行，每行三个整数 vi,wi,si，用空格隔开，分别表示第 i 种物品的体积、价值和数量。

输出格式
输出一个整数，表示最大价值。

数据范围
0 < N ≤ 1000
0 < V ≤ 2000
0 < vi,wi,si ≤ 2000

提示：
本题考查多重背包的二进制优化方法。

解题思路

该题目中，按照朴素解法，其时间复杂度O(V⋅∑i=1Nsi)\mathbf{O(V \cdot \sum_{i=1}^N s_i)}O(V⋅∑i=1N​si​) 最大为 4_000_000_000`，显然是大于int类型的最大值，而且效率也是极低的。
这里可以采用二进制拆分进行优化。

¶二进制优化原理

多重背包中的每种物品有sis_isi​个，朴素解法是枚举0到 sis_isi​的所有数量。
那么，将枚举数量减少，就是优化的主要方向。

如何拆分呢？
二进制拆分的主要思想：任意整数可拆分为2的幂次组合。
如s = 13 -> 拆分为 1，2，4， 6 （1+2+4=7,13-7=6）

和二进制有什么关系？
对于整数kkk，都能找到满足20+21+⋅⋅⋅+2p≤k\mathbf{2^0 + 2^1 + ··· + 2^p \le k}20+21+⋅⋅⋅+2p≤k，而剩余部分r=k−(2p+1−1)\mathbf{r = k - (2^p+1 - 1)}r=k−(2p+1−1)。
最终拆分结果：20,21,...,2p,r\mathbf{2^0,2^1,...,2^p,r}20,21,...,2p,r

拆分出来的任意数量的数字可以组合成1到kkk。
如 13 = 1 + 2 + 4 + 6
1 = 1

当然，上述举例只列举其中部分组合。

¶算法优化

二进制拆分通过利用二进制的稀疏表示特性，可以显著降低计算复杂度。

那么，为什么二进制拆分数量NNN能说成log⁡si\log s_ilogsi​呢？

  1. 拆分项数量分析
  • s可被拆分：{20,21,...,2p,r}\{2^0,2^1,...,2^p,r\}{20,21,...,2p,r}
  • 如果r=0r=0r=0，那么数量减少一个。
    因此总项数NNN满足：

[
N =
\begin{cases}
p+1 & \text{if } r = 0 \

\end{cases}
]

  1. ppp与sss的关系

由以上定义可得，ppp是满足2p≤s<2p+12^p \leq s < 2^{p+1}2p≤s<2p+1的最大整数，即：
[

⌊log⁡2s⌋\lfloor\log_2 s\rfloor⌊log2​s⌋ 向下取整，因此：

[

而在算法复杂度中，底数2，常数项1和δ\deltaδ可被忽略，一般说为N=log⁡2sN=\log_2 sN=log2​s。
